# Civil Works Intelligence

## 1. Problem Statement

Citizens often face difficulties reporting and tracking
civic issues such as potholes, garbage, broken streetlights,
water leakage and sewerage problems.

The system aims to provide a centralized platform where
citizens can report issues and track their resolution,
while administrators can manage, prioritize and assign
complaints.

## 2. Users

### Citizen

- Register
- Login
- Report civic issue
- View own complaints
- Track complaint status
- Add comments

### Admin

- Login
- View all complaints
- Search and filter complaints
- Assign department
- Set priority
- Change complaint status
- Add comments

## 3. Complaint Categories
